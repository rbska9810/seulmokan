# AdSense 재검토 보완 기록 — 2026-10-12

## 진단

반려 사유는 계속 "가치가 별로 없는 콘텐츠"였다. 페이지별 본문을 직접 측정한 결과:

- 활용 가이드 12편의 본문이 편당 600~800자(4~5문단)에 그쳐, 사이트에서 유일한 원문 콘텐츠가 요약 수준이었다.
- 도구 페이지 68개가 모두 같은 7개 소제목 틀로 600~900자 안내를 갖고 있어, 사이트 전체가 템플릿 반복으로 보이기 쉬웠다.
- 무작위 문구를 보여주는 운세 3종과 단순 미니게임 4종이 색인 대상이었다.
- 가이드 페이지에서는 `tool-ui.css`를 불러오지 않아 평수 환산표가 스타일 없이 표시됐다.
- 도구 페이지 상단 메뉴에 활용 가이드 링크가 없었다.

## 이번 변경

1. 활용 가이드 12편을 장문으로 다시 쓰고 10편을 새로 추가했다(총 22편, 본문 편당 약 1,550~3,600자).
   - 모든 글에 핵심 요약, 직접 검산한 계산 예시나 비교표, 자주 묻는 질문, 게시일·수정일을 넣었다. 기준이 바뀌는 주제는 공식 자료 링크를 달았다.
   - 새 글: 최저시급 월급 환산, 대출 상환 방식, 복리와 72의 법칙, 퍼센트와 %p, 만 나이, 날짜·기간 계산, 사직서와 퇴사 절차, 근로계약서 체크리스트, 비밀번호, JSON 오류
   - 2026년 수치(최저임금 10,320원, 국민연금 4.75%, 건강보험 3.595%, 장기요양 13.14%, 고용보험 0.9%, 국민연금 기준소득월액 41만~659만 원)는 계산기 코드와 공개 자료로 교차 확인했다.
2. 도구 페이지 36곳에 관련 가이드 링크를 연결했다. 가이드 페이지에는 관련 가이드 4개와 면책 안내를 넣었다.
3. 운세 3종(오늘의 운세, 띠별 운세, 사주 오행)과 미니게임 4종(업다운, 숫자 기억, 카드 기억, 반응속도)을 실험실로 옮겼다. `noindex`를 적용하고 사이트맵에서 뺐으며 기능은 그대로 유지했다.
4. 홈에서 가이드 6편을 도구 목록보다 위에 노출했다. 도구 페이지 메뉴와 전체 푸터에 활용 가이드 링크를 추가했다.
5. 소개 페이지에 가이드 작성·검수 방식과 정확성의 한계를 추가했다. 업데이트 기록에는 10월 12일 항목을 추가했다.
6. 부가세 계산기 버그를 고쳤다. 합계 110,000원을 '버림'으로 계산하면 부동소수점 오차 때문에 공급가액 99,999원 / 세액 10,001원으로 나왔는데, 정수 기반 계산으로 바꿨다.
7. 가이드 표, 요약, FAQ용 CSS를 `site.css`에 추가했다. 캐시 무효화를 위해 자산 버전도 올렸다.
8. 검증 강화: 가이드 본문이 1,500자 미만이거나 표·절차, FAQ, 날짜가 없으면 `validate-site.mjs`가 실패한다.

## 검증

- `node scripts/validate-site.mjs`: HTML 100개, 핵심 도구 61개, 실험실 7개, 가이드 22편, 사이트맵 91개, 깨진 링크 0, JSON-LD 유효
- `node scripts/audit-all-tools.cjs`: 68개 도구 모두 통과
- 브라우저 확인: 부가세 110,000원 버림 → 100,000원 / 10,000원, 가이드·홈·실험실 모바일 가로 넘침 없음

## 재검토 요청 순서

1. 배포 후 라이브 사이트에서 `/insights/`와 새 가이드 몇 편을 연다.
2. Search Console에 사이트맵을 다시 제출하고 `/insights/`와 대표 가이드 3~5편의 색인 생성을 요청한다.
3. 1~2주쯤 지나 크롤링이 반영된 뒤 AdSense에서 재검토를 요청한다. 바로 다시 신청하면 이전 상태로 평가될 수 있다.
4. 기다리는 동안 주 1~2편씩 새 가이드를 추가하면 "지속적인 콘텐츠 관리" 신호에 도움이 된다.

## 한계

콘텐츠 분량과 품질을 크게 보강했지만 승인을 보장하지는 않는다. 사이트 운영 기간(2026년 9월 시작)과 실제 방문자 수도 평가에 영향을 준다.
