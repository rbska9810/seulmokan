# AdSense 저가치 콘텐츠 보완 기록

작성일: 2026-09-20  
대상: https://www.seulmokan.com/

## 확인한 공식 기준

- Google Publisher Policies: 게시자 콘텐츠가 없거나 가치가 낮은 화면, 복제 콘텐츠, 콘텐츠보다 광고·홍보가 많은 화면에는 광고를 게재할 수 없음.
- AdSense 콘텐츠 및 사용자 경험: 방문 이유가 되는 충분한 고유 콘텐츠, 명확한 탐색, 비슷한 페이지의 통합·확장이 필요함.
- AdSense 가입·승인 안내: 공사 중인 페이지와 자동 생성 또는 독창성이 낮은 페이지에 광고 코드를 두지 말아야 함.
- Google Search 스팸 정책: 키워드 반복, 실질 기능이 없는 페이지, 부가가치 없는 제휴·도어웨이 페이지를 피해야 함.
- 개인정보 공개 기준: 쿠키·웹 비콘·IP 주소와 Google의 파트너 사이트 데이터 이용을 개인정보처리방침에 고지해야 함.

## 2026-09-20 적용 내용

1. 모든 페이지에서 AdSense 실행 스크립트, 광고 자리표시자와 쿠팡 링크·배너를 제거했다. 소유 확인용 메타태그와 `ads.txt`만 유지한다.
2. 65개 도구 중 설명·검증을 마친 27개를 핵심 도구로 선정했다. 각 페이지에 준비 자료, 실제 예시, 결과 해석, 완료 전 확인과 편집 검토일을 별도로 작성했다.
3. 나머지 38개 기능은 삭제하지 않고 `/lab/`으로 분리했다. 각 페이지에 `noindex,follow`를 적용하고 사이트맵에서 제외했다.
4. 퇴직금, 실수령액, 이미지 형식, 누끼 촬영, Excel 가져오기, 부가세, 문서 초안, 브라우저 처리 개인정보에 관한 원문 가이드 8개를 추가했다.
5. 홈을 핵심 도구와 원문 가이드 중심으로 다시 만들고 실험 기능은 한 개의 실험실 링크로 축소했다.
6. 반복 FAQ 구조와 `meta keywords`를 제거하고, WebApplication·Breadcrumb·Article 구조화 데이터만 실제 내용과 일치하게 유지했다.
7. 운영자, 편집·검토 절차, 오류 수정 방법과 수익화 원칙을 소개 페이지에 명시했다.
8. 개인정보처리방침에 브라우저 처리, CDN 로그, 향후 광고 쿠키·웹 비콘·IP 사용과 Google 파트너 사이트 정책 링크를 추가했다.
9. 사이트맵은 색인 가능한 42개 URL만 포함하도록 다시 생성했다.

## 검증 결과

- HTML 82개, 도구 65개, 핵심 도구 27개, 실험실 도구 38개, 원문 가이드 8개
- 색인 가능 canonical과 사이트맵 URL: 42개로 일치
- 깨진 내부 링크: 0
- 광고·제휴 코드/문구 잔존: 0
- 핵심 페이지 장문 중복: 0
- JSON-LD 구문 오류: 0
- 전 도구 초기화, 모바일 가로 넘침, 기본 라이트 테마: 통과
- 계산·게임·문서·파일 다운로드와 AI 배경 제거 실제 실행: 통과

## 재심사 전 운영 순서

1. 배포 후 라이브 홈, 핵심 도구, 가이드, `sitemap.xml`, `robots.txt`를 확인한다.
2. Search Console에서 새 사이트맵을 다시 제출하고 홈과 대표 핵심 페이지 3~5개의 색인 생성을 요청한다.
3. 크롤링과 색인 반영 시간을 둔 뒤 AdSense에서 “문제를 수정했음을 확인합니다”를 선택하고 재검토를 요청한다.
4. 승인 전에는 광고 실행 스크립트와 제휴 배너를 다시 넣지 않는다.
5. 승인 후에도 광고 수가 본문·도구보다 많아지지 않도록 핵심 도구에만 제한적으로 적용한다.

## 주의

이번 변경은 공식 기준에 맞춘 실질적인 품질 보완이지만 승인을 보장하지는 않는다. 색인 상태, 사이트 운영 기간, Google의 재평가 결과도 함께 영향을 줄 수 있다.
