사용가이드

쓸모칸의 도구를 빠르고 안전하게 사용하는 방법을 안내합니다.

홈에서 검색창이나 카테고리 필터로 필요한 도구를 찾고, 도구 페이지의 입력란에 값을 넣은 다음 실행 버튼을 누르세요. 결과 복사가 제공되는 도구는 버튼 한 번으로 클립보드에 저장할 수 있습니다.

도구별 확인 사항

텍스트·개발 도구는 대부분 브라우저 안에서 처리됩니다. 날짜와 단위는 입력 형식을 확인하고, 생성 결과는 복사 전에 한 번 검토하세요.

중요한 계산 결과

급여·금융·건강 계산은 참고값입니다. 세금과 보험료는 적용 연도 및 개인 조건에 따라 달라지므로 중요한 결정 전에는 공식 기준을 다시 확인하세요.

외부 서비스 사용

내 IP 확인과 QR코드 생성기는 기능 수행을 위해 외부 서비스에 요청하며 실행 화면에 데이터 전송 사실을 표시합니다.

운영 원칙

  • 실제로 작동하는 도구만 공개합니다.
  • 가능한 모든 처리는 브라우저 내부에서 수행합니다.
  • 광고가 도구 사용을 방해하지 않도록 배치합니다.
  • 오류와 변경된 계산 기준을 지속적으로 바로잡습니다.
