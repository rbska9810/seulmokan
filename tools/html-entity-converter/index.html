HTML 엔티티 변환기

HTML 특수문자를 엔티티로 바꾸거나 다시 원문으로 복원합니다.

무료로그인 없음모바일 지원브라우저 처리

도구를 불러오는 중입니다.

HTML 엔티티 변환기 사용 방법

HTML 또는 일반 텍스트와 인코딩·디코딩·태그 제거 방식을 선택합니다.

결과에서 확인할 내용

특수문자를 안전한 엔티티로 바꾸거나 표시 텍스트만 추출합니다.

이 도구가 필요한 상황

HTML 문서에 그대로 표시할 특수문자를 엔티티로 바꾸거나 인코딩된 문자열을 읽을 수 있게 복원합니다.

실제 사용 예시

“안내”를 문자 그대로 보여주려면 꺾쇠괄호를 <와 >로 바꿔야 합니다. 복원한 문자열을 다시 HTML로 실행하면 태그로 해석될 수 있습니다.

결과를 정확히 읽는 방법

  • &처럼 앰퍼샌드는 다른 엔티티보다 먼저 처리해야 이중 인코딩을 피할 수 있습니다.
  • 엔티티를 디코딩해도 그 결과가 안전한 HTML이라는 뜻은 아닙니다.
  • 숫자 엔티티와 이름 엔티티는 같은 문자를 나타낼 수 있습니다.

완료 전 확인

사용자 입력을 페이지에 넣을 때는 변환 결과를 HTML이 아닌 텍스트로 삽입하세요.

사용 전 꼭 확인하세요

태그 제거 결과는 HTML 구조와 줄바꿈을 완전히 보존하지 않습니다.
