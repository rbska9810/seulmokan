CSV ↔ JSON 변환기 사용 방법

CSV 또는 JSON과 CSV 구분자, 값 자동 변환 여부를 선택합니다.

결과에서 확인할 내용

인용부호를 처리해 두 형식 사이를 양방향 변환합니다.

이 도구가 필요한 상황

간단한 표 데이터를 CSV와 JSON 배열 사이에서 바꿔 API 테스트나 스프레드시트 작업에 활용합니다. 변환 전에 데이터 구조와 머리글 사용 여부를 확인할 수 있습니다.

실제 사용 예시

첫 행이 name,team이고 다음 행이 민수,기획이면 JSON 객체 배열의 키는 name과 team이 됩니다. JSON에서 CSV로 바꿀 때 객체마다 키가 다르면 빈 셀이 생길 수 있습니다.

결과를 정확히 읽는 방법

  • 쉼표가 포함된 셀은 큰따옴표로 감싸고 내부 큰따옴표는 두 번 작성해야 합니다.
  • 중첩 객체와 배열은 평면 CSV 한 셀로 자연스럽게 표현되지 않으므로 단순 표에 적합합니다.
  • Excel 호환을 위해 CSV 다운로드에는 UTF-8 BOM을 사용할 수 있습니다.

계산 방식

CSV는 쉼표로 열을 구분하는 표 형식이고 JSON은 객체와 배열로 구조를 표현하는 형식입니다. 첫 행을 머리글로 보면 각 행이 “열 이름: 값” 객체가 되어 JSON 배열로 변환되고, 반대로 JSON 객체 배열은 키 모음이 머리글이 되어 CSV 행으로 펼쳐집니다.

상황별 계산 사례

  • “name,team / 민수,기획 / 지아,디자인”을 변환하면 [{"name":"민수","team":"기획"},{"name":"지아","team":"디자인"}]이 됩니다.
  • 셀 안에 쉼표가 있으면 큰따옴표로 감싸야 합니다. 예: "서울, 강남",50.
  • 객체마다 키가 다르면 CSV로 바꿀 때 없는 키는 빈 셀로 남습니다.
  • 엑셀에서 한글 CSV가 깨질 때는 UTF-8 BOM이 붙은 파일로 저장하거나 엑셀의 “데이터 가져오기”에서 UTF-8을 선택하면 해결되는 경우가 많습니다.

자주 하는 실수

  • 큰따옴표 안의 큰따옴표를 두 번 쓰지 않아 열이 밀리는 실수.
  • 숫자 앞의 0(우편번호, 전화번호)이 엑셀에서 사라지는 것을 놓치는 실수.
  • 중첩 객체나 배열이 있는 JSON을 평면 CSV로 바꾸려는 실수.
  • 구분자가 쉼표가 아니라 세미콜론·탭인 파일을 쉼표로 읽는 실수.

자주 묻는 질문

숫자는 문자열로 변환되나요?

JSON 변환 시 숫자처럼 보이는 값을 숫자로 읽을지 문자열로 둘지는 옵션과 데이터에 따라 다르니 결과 미리보기에서 확인하세요.

머리글이 없는 CSV는 어떻게 하나요?

머리글 없음 옵션으로 열 번호를 키로 쓰거나, 먼저 첫 행에 열 이름을 추가하세요.

데이터가 서버로 전송되나요?

브라우저 안에서 변환하며 서버로 전송하지 않습니다.
