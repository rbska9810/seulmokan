CSV ↔ JSON 변환기

표 형식 데이터를 CSV와 JSON 사이에서 양방향 변환합니다.

도구를 불러오는 중입니다.

CSV ↔ JSON 변환기 사용 방법

CSV 또는 JSON과 CSV 구분자, 값 자동 변환 여부를 선택합니다.

결과에서 확인할 내용

인용부호를 처리해 두 형식 사이를 양방향 변환합니다.

이 도구가 필요한 상황

간단한 표 데이터를 CSV와 JSON 배열 사이에서 바꿔 API 테스트나 스프레드시트 작업에 활용합니다. 변환 전에 데이터 구조와 머리글 사용 여부를 확인할 수 있습니다.

실제 사용 예시

첫 행이 name,team이고 다음 행이 민수,기획이면 JSON 객체 배열의 키는 name과 team이 됩니다. JSON에서 CSV로 바꿀 때 객체마다 키가 다르면 빈 셀이 생길 수 있습니다.

결과를 정확히 읽는 방법

  • 쉼표가 포함된 셀은 큰따옴표로 감싸고 내부 큰따옴표는 두 번 작성해야 합니다.
  • 중첩 객체와 배열은 평면 CSV 한 셀로 자연스럽게 표현되지 않으므로 단순 표에 적합합니다.
  • Excel 호환을 위해 CSV 다운로드에는 UTF-8 BOM을 사용할 수 있습니다.

완료 전 확인

행 수, 열 이름, 따옴표가 포함된 셀을 미리보기에서 확인한 뒤 원본을 보관하세요.

지원 범위

간단한 쉼표 구분 표를 빠르게 변환하는 도구입니다. 셀 내부 줄바꿈이나 복잡한 인용부호를 포함한 CSV는 전문 스프레드시트 프로그램으로 결과를 다시 확인하세요.
