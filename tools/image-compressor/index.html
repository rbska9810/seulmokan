이미지 용량 줄이기

여러 이미지를 브라우저에서 일괄 압축하고 개별 파일 또는 ZIP으로 다운로드합니다.

도구를 불러오는 중입니다.

이미지 용량 줄이기 사용 순서

  1. 준비: JPG, PNG 또는 WebP 이미지와 출력 형식, 화질, 최대 크기를 선택합니다.
  2. 실행: 입력 형식과 선택 옵션을 확인한 뒤 실행 버튼을 누릅니다. 오류가 있으면 해당 항목 옆 안내부터 수정합니다.
  3. 확인: 압축 전후 용량과 감소율을 비교하고 개별 파일 또는 ZIP으로 내려받습니다.

이 도구가 필요한 상황

메신저·쇼핑몰·공공기관은 업로드 파일의 용량과 가로세로 크기를 제한합니다. 이 도구는 원본을 서버에 올리지 않고 여러 장을 같은 조건으로 줄여, 전후 용량과 감소율을 확인한 뒤 ZIP으로 받을 수 있게 합니다.

실제 사용 예시

4,000×3,000px JPG 사진 12장을 최대 1,920px, WebP 82%로 처리하면 긴 변이 먼저 줄어듭니다. 결과 표에서 각 파일의 원본·변환 용량을 비교하고, 글자나 제품 라벨이 뭉개진 사진만 화질을 높여 다시 처리하는 방식이 안전합니다.

결과를 정확히 읽는 방법

  • 사진은 JPG 또는 WebP가 대체로 작고, 로고·도표처럼 경계가 선명한 이미지는 PNG가 유리합니다.
  • PNG를 PNG로 저장하면 무손실 특성 때문에 화질 슬라이더만으로 용량이 크게 줄지 않을 수 있습니다.
  • 움직이는 GIF는 첫 프레임 보존 문제가 있어 처리 대상에서 제외합니다. 원본은 별도로 보관하세요.

완료 전 확인

압축 후에는 확대해서 글자와 얼굴 경계를 확인하고, 출력 형식·픽셀 크기·파일명을 제출처 조건과 비교하세요.

개인정보와 한계

별도 안내가 없는 계산·파일 도구는 현재 브라우저에서 처리하며 입력 내용을 쓸모칸 서버에 저장하지 않습니다. 결과가 계약, 세금, 급여 또는 법률 판단에 영향을 준다면 최신 공식 자료와 담당 기관의 결과를 함께 확인하세요.
