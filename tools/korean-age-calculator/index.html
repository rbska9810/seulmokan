만 나이 계산기

생년월일을 기준으로 오늘의 만 나이를 계산합니다.

무료로그인 없음모바일 지원브라우저 처리

도구를 불러오는 중입니다.

만 나이 계산기 사용 방법

생년월일과 확인하려는 기준일을 입력합니다.

결과에서 확인할 내용

기준일의 만 나이, 연 나이, 살아온 날과 다음 생일까지 일수를 계산합니다.

이 도구가 필요한 상황

생년월일과 기준일로 만 나이, 연 나이와 세는나이를 구분해 보여 줍니다.

실제 사용 예시

1998년 10월 27일생의 2026년 9월 12일 기준 만 나이는 생일 전이라 27세, 연 나이는 2026−1998=28세, 세는나이는 29세입니다.

결과를 정확히 읽는 방법

  • 만 나이는 태어난 날 0세이며 생일마다 한 살 증가합니다.
  • 연 나이는 기준 연도에서 출생 연도를 뺀 값으로 생일을 따지지 않습니다.
  • 세는나이는 태어난 해 1세에서 시작해 새해마다 한 살 증가합니다.

완료 전 확인

법령·기관에서 요구하는 나이 기준이 만 나이인지 별도 기준인지 확인하세요.
