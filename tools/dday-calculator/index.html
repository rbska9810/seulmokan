D-Day 계산기

선택한 날짜까지 남은 날 또는 지난 날을 계산합니다.

도구를 불러오는 중입니다.

쓸모칸 편집팀 검토최종 확인 2026-09-20

D-Day 계산기 사용 순서

  1. 준비: 목표 날짜, 선택적 일정 이름과 오늘 포함 여부를 입력합니다.
  2. 실행: 입력 형식과 선택 옵션을 확인한 뒤 실행 버튼을 누릅니다. 오류가 있으면 해당 항목 옆 안내부터 수정합니다.
  3. 확인: D-Day, 주·일 환산과 목표일이 남았는지 지났는지 보여줍니다.

이 도구가 필요한 상황

기준일과 목표일 사이의 남은 날·지난 날을 계산하고 달력 기준의 주·일 정보를 함께 보여줍니다. 시험·행사·계약 마감처럼 특정 날짜를 추적할 때 사용합니다.

실제 사용 예시

오늘을 D-0으로 볼지 목표일을 D-Day로 볼지는 서비스마다 표기가 다릅니다. 이 도구는 날짜 차이를 명시하고, 목표일이 지났다면 지난 일수로 구분합니다.

결과를 정확히 읽는 방법

  • 시간은 제외하고 달력 날짜만 비교합니다.
  • 시험 접수 마감처럼 시각이 정해진 일정은 별도의 시간 알림이 필요합니다.
  • 기기의 날짜나 시간대가 잘못되어 있으면 오늘 기준 결과도 달라집니다.

완료 전 확인

공식 일정의 마감 시각과 시간대를 확인하고 캘린더 알림을 별도로 설정하세요.

개인정보와 한계

별도 안내가 없는 계산·파일 도구는 현재 브라우저에서 처리하며 입력 내용을 쓸모칸 서버에 저장하지 않습니다. 결과가 계약, 세금, 급여 또는 법률 판단에 영향을 준다면 최신 공식 자료와 담당 기관의 결과를 함께 확인하세요.
