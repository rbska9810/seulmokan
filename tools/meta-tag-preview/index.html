메타태그 미리보기 사용 방법

페이지 제목, 설명과 실제 공개 URL을 입력합니다.

결과에서 확인할 내용

검색결과 형태의 미리보기와 제목·설명 길이를 표시합니다.

이 도구가 필요한 상황

페이지 제목·설명·대표 이미지 URL을 입력해 검색결과와 소셜 공유 카드의 형태를 한 화면에서 점검합니다. 미리보기와 함께 복사할 수 있는 기본 메타태그를 제공합니다.

실제 사용 예시

제목에는 페이지의 실제 기능을 앞쪽에 쓰고 사이트명은 뒤에 둡니다. 설명은 같은 키워드를 반복하기보다 사용자가 얻는 결과와 제한을 한두 문장으로 적는 편이 좋습니다.

결과를 정확히 읽는 방법

  • 검색엔진은 기기와 검색어에 따라 제목과 설명을 다시 작성할 수 있어 미리보기와 완전히 같지 않을 수 있습니다.
  • 대표 이미지는 절대 HTTPS URL과 1200×630 비율을 권장하며 robots가 접근할 수 있어야 합니다.
  • 카카오톡과 SNS는 이전 결과를 캐시하므로 배포 직후 갱신되지 않을 수 있습니다.

계산 방식

검색 결과 제목과 설명은 글자 수가 아니라 화면에 차지하는 폭(픽셀)을 기준으로 잘립니다. 한글은 영문보다 폭이 넓어 같은 글자 수에서도 더 일찍 잘리므로, 한글 제목은 30자 안팎, 설명은 80자 안팎을 점검 기준으로 삼는 편이 안전합니다. 공유 카드용 대표 이미지는 1200×630(약 1.91 대 1) 비율이 널리 쓰입니다.

상황별 계산 사례

  • 제목은 “페이지의 실제 기능 + 사이트명” 순서가 좋습니다. 예를 들어 “퇴직금 계산기 | 평균임금 자동 계산 | 사이트명”처럼 핵심어를 앞에 두면 잘려도 의미가 남습니다.
  • 설명에는 같은 키워드를 반복하지 말고 사용자가 얻는 결과와 제한을 한두 문장으로 씁니다.
  • 1200×630 이미지를 쓰면 가로 대 세로 비율이 약 1.905 대 1이라 카카오톡·페이스북·X의 큰 카드에서 가장자리가 덜 잘립니다.
  • 같은 사이트의 모든 페이지가 같은 제목과 설명을 쓰면 검색엔진이 중복으로 보기 쉬우므로 페이지마다 고유하게 작성합니다.

자주 하는 실수

  • 제목과 설명을 모든 페이지에 똑같이 복사하는 실수.
  • canonical, og:url, 실제 접속 주소가 서로 다른 실수.
  • 대표 이미지를 상대 경로나 http 주소로 적어 공유 카드에 나오지 않는 실수.
  • 검색엔진이 문구를 바꿔 보여 줄 수 있다는 점을 모르고 미리보기와 다르다고 오해하는 실수.

자주 묻는 질문

미리보기와 실제 검색 결과가 다른 이유는 무엇인가요?

검색엔진은 검색어와 기기에 맞춰 제목과 설명을 다시 만들 수 있습니다. 미리보기는 대략적인 길이와 모양을 점검하는 용도입니다.

공유 카드가 갱신되지 않아요.

카카오톡과 SNS는 이전 결과를 캐시합니다. 각 서비스의 공유 디버거나 캐시 초기화 도구를 쓰면 갱신됩니다.

meta keywords는 필요한가요?

구글은 meta keywords를 순위에 사용하지 않는다고 밝혔습니다. 제목과 설명, 본문 품질에 집중하는 편이 낫습니다.

완료 전 확인

실제 공개 URL, canonical, og:url이 같은 주소를 가리키는지 확인하고 제목·설명을 페이지마다 고유하게 작성하세요.
