메타태그 미리보기 사용 순서

  1. 준비: 페이지 제목, 설명과 실제 공개 URL을 입력합니다.
  2. 실행: 입력 형식과 선택 옵션을 확인한 뒤 실행 버튼을 누릅니다. 오류가 있으면 해당 항목 옆 안내부터 수정합니다.
  3. 확인: 검색결과 형태의 미리보기와 제목·설명 길이를 표시합니다.

이 도구가 필요한 상황

페이지 제목·설명·대표 이미지 URL을 입력해 검색결과와 소셜 공유 카드의 형태를 한 화면에서 점검합니다. 미리보기와 함께 복사할 수 있는 기본 메타태그를 제공합니다.

실제 사용 예시

제목에는 페이지의 실제 기능을 앞쪽에 쓰고 사이트명은 뒤에 둡니다. 설명은 같은 키워드를 반복하기보다 사용자가 얻는 결과와 제한을 한두 문장으로 적는 편이 좋습니다.

결과를 정확히 읽는 방법

  • 검색엔진은 기기와 검색어에 따라 제목과 설명을 다시 작성할 수 있어 미리보기와 완전히 같지 않을 수 있습니다.
  • 대표 이미지는 절대 HTTPS URL과 1200×630 비율을 권장하며 robots가 접근할 수 있어야 합니다.
  • 카카오톡과 SNS는 이전 결과를 캐시하므로 배포 직후 갱신되지 않을 수 있습니다.

완료 전 확인

실제 공개 URL, canonical, og:url이 같은 주소를 가리키는지 확인하고 제목·설명을 페이지마다 고유하게 작성하세요.

개인정보와 한계

별도 안내가 없는 계산·파일 도구는 현재 브라우저에서 처리하며 입력 내용을 쓸모칸 서버에 저장하지 않습니다. 결과가 계약, 세금, 급여 또는 법률 판단에 영향을 준다면 최신 공식 자료와 담당 기관의 결과를 함께 확인하세요.
