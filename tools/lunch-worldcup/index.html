점심 메뉴 월드컵

32가지 기본 메뉴 사진에서 대결을 이어가 오늘의 점심을 결정합니다.

무료로그인 없음모바일 지원브라우저 처리

도구를 불러오는 중입니다.

점심 메뉴 월드컵 사용 방법

종합 32강·한식 16강·간편 메뉴·세계 메뉴 중 하나를 고릅니다. 원하는 경우에만 직접 메뉴를 입력합니다.

결과에서 확인할 내용

음식 사진이 있는 두 메뉴 중 하나를 계속 선택해 최종 우승 메뉴와 선택 경로를 확인합니다.

이 도구가 필요한 상황

여러 메뉴를 한꺼번에 비교하기 어렵거나 함께 먹을 메뉴를 빠르게 정해야 할 때 두 개씩 선택하며 후보를 줄입니다. 기본 사진 메뉴를 바로 시작할 수 있고 원하는 후보로 바꿀 수도 있습니다.

실제 사용 예시

빠른 8강을 선택하면 한식·중식·양식 메뉴가 두 개씩 제시됩니다. 매 대결에서 오늘 더 먹고 싶은 메뉴를 고르면 마지막에 우승 메뉴와 전체 선택 흐름을 확인할 수 있습니다.

결과를 정확히 읽는 방법

  • 결과는 사용자의 선택으로 결정되며 음식점 추천이나 영양 판단이 아닙니다.
  • 알레르기·식단 제한이 있다면 시작 전에 해당 메뉴를 후보에서 제외하세요.
  • 여럿이 사용할 때는 같은 화면을 보며 번갈아 선택하거나 우승 메뉴를 후보로 다시 투표할 수 있습니다.

완료 전 확인

실제 주문 전 영업 여부, 배달 가능 지역, 알레르기 성분과 가격을 음식점에서 확인하세요.

점심 메뉴를 빠르게 고르는 순서

먼저 인원과 식사 시간을 확인하고 매운맛·국물·면·밥처럼 오늘 피하고 싶은 조건을 정하세요. 혼자라면 종합 32강, 시간이 부족하면 간편 메뉴 8강, 여럿이라면 한식 16강처럼 후보 수를 줄여 시작하는 편이 빠릅니다.

선택 가능한 메뉴 구성

김치찌개·제육볶음·비빔밥·국밥 같은 한식부터 돈가스·초밥·짜장면·쌀국수·파스타·샌드위치까지 32개 기본 후보를 제공합니다. 기본 목록이 맞지 않으면 4~32개의 메뉴를 한 줄에 하나씩 입력해 우리 팀만의 월드컵을 만들 수 있습니다.

자주 묻는 질문

목록을 직접 입력하지 않아도 되나요?

네. 종합 32강, 한식 16강, 간편 메뉴 8강, 세계 메뉴 8강 중 하나를 선택하고 바로 시작할 수 있습니다.

여러 명이 함께 고를 때는 어떻게 하나요?

대결마다 다수결로 하나를 고르거나 사람별로 번갈아 선택하세요. 마지막 우승 메뉴가 부담스럽다면 준우승 메뉴와 한 번 더 최종 투표하면 됩니다.

결과를 친구에게 보낼 수 있나요?

메뉴판 링크 공유 버튼으로 선택한 프리셋 또는 직접 만든 후보 목록을 전달할 수 있습니다. 공유 링크에는 이름이나 연락처 같은 개인정보를 넣지 마세요.

사용 전 꼭 확인하세요

사진은 메뉴를 구분하기 위한 예시이며 실제 판매 음식과 다를 수 있습니다. 알레르기·식단 조건은 직접 확인하세요.
