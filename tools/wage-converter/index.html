시급·월급 변환기

시급·월급 변환기 사용 순서

  1. 준비: 시급, 주 근로시간·근무일수와 주휴수당 포함 여부를 입력합니다.
  2. 실행: 입력 형식과 선택 옵션을 확인한 뒤 실행 버튼을 누릅니다. 오류가 있으면 해당 항목 옆 안내부터 수정합니다.
  3. 확인: 주급, 월 환산액, 연봉과 유급 처리 시간을 보여줍니다.

이 도구가 필요한 상황

시급과 주 근무시간을 월급·연봉으로 환산하거나 월급을 시간당 금액으로 나눕니다. 근무 조건을 비교할 때 동일한 시간 기준으로 맞추기 위한 참고 계산입니다.

실제 사용 예시

주 40시간 근무자의 월 환산시간은 주휴시간 포함 여부에 따라 달라집니다. 단순히 40×4주로 계산하면 법정 주휴수당이나 월평균 주 수가 빠질 수 있습니다.

결과를 정확히 읽는 방법

  • 주휴수당 적용 여부는 근로시간과 근무 조건에 따라 달라집니다.
  • 연장·야간·휴일근로 가산수당과 식대·상여금은 기본 환산에 포함되지 않습니다.
  • 최저임금 판단은 임금 산입범위와 소정근로시간을 함께 검토해야 합니다.

완료 전 확인

근로계약서의 소정근로시간과 주휴 조건을 확인하고 공식 최저임금 계산기와 대조하세요.

개인정보와 한계

별도 안내가 없는 계산·파일 도구는 현재 브라우저에서 처리하며 입력 내용을 쓸모칸 서버에 저장하지 않습니다. 결과가 계약, 세금, 급여 또는 법률 판단에 영향을 준다면 최신 공식 자료와 담당 기관의 결과를 함께 확인하세요.
