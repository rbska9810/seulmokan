이미지 자르기

이미지 자르기 사용 순서

  1. 준비: JPG, PNG 또는 WebP 이미지를 선택하고 자를 비율과 영역, 회전·반전 옵션을 조절합니다.
  2. 실행: 입력 형식과 선택 옵션을 확인한 뒤 실행 버튼을 누릅니다. 오류가 있으면 해당 항목 옆 안내부터 수정합니다.
  3. 확인: 잘라낸 결과를 미리 보고 PNG, JPG 또는 WebP 파일로 다운로드합니다.

이 도구가 필요한 상황

프로필, 썸네일, 증명사진처럼 정해진 비율이 필요할 때 원본 해상도를 기준으로 영역을 선택하고 회전·반전한 결과를 저장합니다. 화면에 작게 보이는 미리보기만 잘라 화질이 떨어지지 않도록 원본 좌표로 다시 계산합니다.

실제 사용 예시

가로 4,032px 사진에서 1:1을 선택한 뒤 얼굴 중심으로 영역을 옮기면 선택 영역의 원본 픽셀 수로 정사각형 파일을 만듭니다. JPG는 투명도를 지원하지 않으므로 비어 있는 부분이 흰색으로 채워집니다.

결과를 정확히 읽는 방법

  • 자유 비율은 모서리를 끌어 폭과 높이를 독립적으로 바꿀 수 있습니다.
  • 90도 회전 후에도 원본 좌표를 다시 계산하므로 화면 캔버스 크기보다 큰 결과를 얻을 수 있습니다.
  • 증명사진 규격은 기관마다 다릅니다. 3:4는 비율만 맞추며 얼굴 크기나 실제 인쇄 치수를 보증하지 않습니다.

완료 전 확인

다운로드한 파일의 픽셀 크기와 방향을 확인하고, 원본보다 크게 확대 저장하지 않았는지 살펴보세요.

개인정보와 한계

별도 안내가 없는 계산·파일 도구는 현재 브라우저에서 처리하며 입력 내용을 쓸모칸 서버에 저장하지 않습니다. 결과가 계약, 세금, 급여 또는 법률 판단에 영향을 준다면 최신 공식 자료와 담당 기관의 결과를 함께 확인하세요.
