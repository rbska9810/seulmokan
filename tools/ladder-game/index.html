사다리타기

참가자 이름과 당첨 인원을 정해 애니메이션 사다리로 추첨합니다.

무료로그인 없음모바일 지원브라우저 처리

도구를 불러오는 중입니다.

실험실 기능

이 페이지는 기능을 유지하되 검색 색인과 광고 대상에서 제외했습니다. 사용 의견을 반영해 설명과 검증 기준을 보강한 뒤 핵심 도구로 전환합니다.

사다리타기 사용 방법

  1. 참가 인원과 당첨 인원을 정한 뒤 생성된 입력칸에 참가자 이름을 하나씩 적습니다.
  2. 사다리를 만든 뒤 참가자별 결과 보기를 누르면 경로가 위에서 아래로 움직이며 당첨 여부를 보여줍니다.

사용 전 확인

같은 이름은 중복 입력할 수 없으며 새 사다리를 만들면 결과가 달라집니다. 추첨 전 참가자와 당첨 인원을 함께 확인하세요.

추첨 방식

브라우저의 보안 난수로 가로선을 구성한 실제 사다리를 만들고 각 출발점의 경로를 따라 결과를 결정합니다. 생성한 뒤에는 참가자별 경로를 하나씩 확인할 수 있습니다.
