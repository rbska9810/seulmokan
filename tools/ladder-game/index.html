사다리타기

도구를 불러오는 중입니다.

사다리타기 사용 방법

참가 인원과 당첨 인원을 정한 뒤 생성된 입력칸에 참가자 이름을 하나씩 적습니다.

결과에서 확인할 내용

사다리를 만든 뒤 참가자별 결과 보기를 누르면 경로가 위에서 아래로 움직이며 당첨 여부를 보여줍니다.

이 도구가 필요한 상황

여러 참가자와 결과를 연결하는 사다리 경로를 화면에서 따라가며 추첨 과정을 공유합니다.

실제 사용 예시

참가자 4명과 당첨 1개를 지정한 뒤 사다리를 만들고 각 사람의 경로를 위에서 아래로 확인할 수 있습니다. 결과를 보기 전에는 참가자 순서와 당첨 개수를 확정하세요.

결과를 정확히 읽는 방법

  • 가로선 하나를 지날 때마다 이웃한 세로줄로 이동합니다.
  • 참가자 이름이 같으면 결과를 구분하기 어려우니 서로 다른 표시 이름을 사용하세요.
  • 게임 결과는 오락용이며 경품·금전 거래의 공정성을 인증하지 않습니다.

완료 전 확인

화면에 표시된 출발점·도착점·선택 경로가 일치하는지 결과 공개 전에 확인하세요.

추첨 방식

브라우저의 보안 난수로 가로선을 구성한 실제 사다리를 만들고 각 출발점의 경로를 따라 결과를 결정합니다. 생성한 뒤에는 참가자별 경로를 하나씩 확인할 수 있습니다.

사용 전 꼭 확인하세요

같은 이름은 중복 입력할 수 없으며 새 사다리를 만들면 결과가 달라집니다. 추첨 전 참가자와 당첨 인원을 함께 확인하세요.
