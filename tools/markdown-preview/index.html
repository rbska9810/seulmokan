마크다운 미리보기 사용 방법

기본 마크다운 문법을 입력합니다.

결과에서 확인할 내용

제목, 목록, 링크, 강조와 코드의 렌더링 결과를 실시간 표시합니다.

이 도구가 필요한 상황

제목·목록·강조·코드 같은 기본 마크다운 문법을 입력하고 렌더링 모양을 바로 확인합니다.

실제 사용 예시

# 제목을 입력하면 큰 제목으로, - 항목을 여러 줄 입력하면 목록으로 보입니다. 복잡한 표나 각주까지 지원하는 완전한 마크다운 편집기는 아닙니다.

결과를 정확히 읽는 방법

  • 입력한 HTML은 실행하지 않고 문자로 표시해 스크립트 실행을 막습니다.
  • 코드 블록과 인라인 코드의 문법은 줄바꿈 위치에 영향을 받습니다.
  • 플랫폼마다 마크다운 확장 문법이 달라 실제 게시 결과와 다를 수 있습니다.

계산 방식

마크다운은 간단한 기호로 문서 구조를 표시하는 형식입니다. “# 제목”은 큰 제목, “- 항목”은 목록, “**굵게**”는 강조, 백틱(`)은 코드를 뜻합니다. 같은 문서도 렌더러(CommonMark, GitHub 방식 등)에 따라 표, 취소선, 줄바꿈 처리가 조금씩 달라집니다.

상황별 계산 사례

  • “## 설치 방법” 아래에 “1. 파일 받기 / 2. 실행하기”를 쓰면 번호 목록으로 렌더링됩니다.
  • #과 제목 사이에 공백이 없으면(#제목) 제목이 아니라 일반 문자로 처리되는 렌더러가 많습니다.
  • 줄바꿈은 줄 끝에 공백 두 칸을 넣거나 빈 줄로 문단을 나눠야 하는 경우가 많습니다.
  • 코드 블록은 백틱 세 개로 감싸고 언어 이름을 붙이면 문법 강조가 적용되는 서비스가 많습니다.

자주 하는 실수

  • 목록 들여쓰기를 탭과 공백으로 섞어 중첩이 깨지는 실수.
  • 표 구분선(|---|)의 열 개수를 맞추지 않는 실수.
  • HTML 태그가 그대로 표시되는데 서비스가 허용하는지 확인하지 않는 실수.

자주 묻는 질문

미리보기와 실제 게시 결과가 다른 이유는 무엇인가요?

서비스마다 지원하는 확장 문법과 스타일이 달라서입니다. 최종 게시 화면에서 한 번 더 확인하세요.

입력한 HTML이 실행되나요?

안전을 위해 실행하지 않고 문자로 표시합니다.

README 작성에 쓸 수 있나요?

기본 문법은 GitHub README와 같지만 표와 체크박스는 서비스별 확장 문법일 수 있습니다.
