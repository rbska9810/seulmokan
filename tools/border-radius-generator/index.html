Border Radius 생성기 사용 방법

  1. 입력값 준비: 네 모서리 값과 px·% 단위를 선택합니다.
  2. 실행과 확인: 필요한 옵션을 고른 다음 계산·변환·생성 버튼을 누릅니다. 잘못된 값은 결과 영역에 수정 방법과 함께 표시됩니다.
  3. 결과 활용: 도형 미리보기와 border-radius 코드를 생성합니다.

입력값과 결과 읽는 법

네 모서리 값을 조절해 border-radius 코드와 모양을 만듭니다. 입력 범위가 있는 숫자와 날짜는 범위를 벗어나면 계산하지 않으며, 결과는 한국어 숫자 표기와 단위를 함께 표시합니다. 초기화 버튼으로 예시값을 복원하고 Ctrl 또는 ⌘ + Enter로 빠르게 실행할 수 있습니다.

사용 전 확인사항

퍼센트 반지름은 요소의 가로·세로 크기에 따라 모양이 달라집니다.

개인정보와 처리 방식

대부분의 계산과 변환은 현재 브라우저에서 실행되어 입력값을 쓸모칸 서버에 저장하지 않습니다. 외부 연결이 필요한 기능은 실행 영역과 개인정보처리방침에 전송 대상과 목적을 표시합니다.
