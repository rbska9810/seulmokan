AI 누끼 따기

음식·상품·인물 사진을 외부 전송 없이 범용 브라우저 AI로 정밀하게 분리합니다.

무료로그인 없음모바일 지원브라우저 처리

도구를 불러오는 중입니다.

쓸모칸 편집팀 검토최종 확인 2026-09-20

AI 누끼 따기 사용 순서

  1. 준비: 음식·상품·인물 등이 선명하게 나온 JPG, PNG 또는 WebP 이미지 한 장을 선택하거나 끌어 놓습니다.
  2. 실행: 입력 형식과 선택 옵션을 확인한 뒤 실행 버튼을 누릅니다. 오류가 있으면 해당 항목 옆 안내부터 수정합니다.
  3. 확인: 정밀 또는 빠른 범용 AI 모델과 가장자리 정리 강도를 고른 뒤 투명 PNG로 다운로드합니다.

이 도구가 필요한 상황

제품·음식·인물 사진에서 피사체를 분리해 투명 PNG로 저장합니다. 사진은 브라우저 메모리에서 처리되고 AI 모델 파일만 외부 CDN에서 내려받으므로 업로드형 서비스에 원본을 전송하고 싶지 않을 때 유용합니다.

실제 사용 예시

흰 접시에 담긴 음식처럼 피사체와 배경 색이 비슷하면 정밀 모델과 “흰 테두리 줄이기”를 사용하세요. 머리카락이나 반투명 유리의 일부가 잘리면 “자연스럽게”로 되돌려 두 결과를 비교하는 편이 좋습니다.

결과를 정확히 읽는 방법

  • 정밀 모델은 첫 실행 다운로드와 추론 시간이 더 길지만 음식·상품 경계에 유리합니다.
  • 가장자리 정리는 AI가 만든 알파 채널의 대비를 조절하며, 원본에 없던 세부 정보를 복원하지는 못합니다.
  • 역광, 심한 그림자, 투명 물체, 배경과 같은 색의 물체는 자동 분리가 어려울 수 있습니다.

완료 전 확인

체커보드 배경에서 외곽을 확대해 흰 잔상과 잘린 부분을 확인한 뒤 PNG를 저장하세요.

개인정보와 한계

별도 안내가 없는 계산·파일 도구는 현재 브라우저에서 처리하며 입력 내용을 쓸모칸 서버에 저장하지 않습니다. 결과가 계약, 세금, 급여 또는 법률 판단에 영향을 준다면 최신 공식 자료와 담당 기관의 결과를 함께 확인하세요.
