도구를 불러오는 중입니다.

숫자 기억력 테스트 사용 방법

시작 버튼을 누르고 잠시 보이는 숫자를 기억합니다.

결과에서 확인할 내용

3자리부터 한 자리씩 늘어나는 문제와 3번의 기회, 브라우저 최고 기록을 제공합니다.

이 도구가 필요한 상황

잠깐 표시되는 숫자를 기억해 입력하며 단계별 길이와 성공 기록을 확인합니다.

실제 사용 예시

네 자리 숫자가 나타났다가 사라지면 순서를 그대로 입력합니다. 숫자 집합이 같아도 순서가 다르면 실패입니다.

결과를 정확히 읽는 방법

  • 표시 시간과 화면 크기가 기기마다 체감 난이도를 바꿉니다.
  • 한 번의 점수는 수면과 집중도에 영향을 받습니다.
  • 의학적 기억력 검사나 진단 도구가 아닙니다.

완료 전 확인

기록을 비교할 때 같은 난이도와 같은 화면 조건을 사용하세요.

사용 전 꼭 확인하세요

순간 기억 게임 결과는 인지능력 또는 건강 상태를 진단하지 않습니다.
