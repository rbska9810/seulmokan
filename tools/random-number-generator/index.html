로또 번호 추첨기 사용 방법

  1. 입력값 준비: 로또 6/45 또는 일반 범위, 게임 수, 제외수와 중복·정렬 여부를 입력합니다.

입력값과 결과 읽는 법

로또 6/45 번호를 여러 게임 추첨하고 제외수와 일반 난수 범위도 설정합니다. 입력 범위가 있는 숫자와 날짜는 범위를 벗어나면 계산하지 않으며, 결과는 한국어 숫자 표기와 단위를 함께 표시합니다. 초기화 버튼으로 예시값을 복원하고 Ctrl 또는 ⌘ + Enter로 빠르게 실행할 수 있습니다.
