로또 번호 추첨기

로또 6/45 번호를 여러 게임 추첨하고 제외수와 일반 난수 범위도 설정합니다.

무료로그인 없음모바일 지원브라우저 처리

도구를 불러오는 중입니다.

로또 번호 추첨기 사용 방법

로또 6/45 또는 일반 범위, 게임 수, 제외수와 중복·정렬 여부를 입력합니다.

결과에서 확인할 내용

편향을 줄인 브라우저 보안 난수로 최대 5게임의 번호를 추첨합니다.

이 도구가 필요한 상황

설정한 범위에서 원하는 개수의 숫자를 뽑고 중복 허용 여부를 선택합니다.

실제 사용 예시

1~45 중 6개를 중복 없이 고르면 여섯 숫자가 모두 달라야 합니다. 제외 숫자를 지정했다면 추첨 가능한 후보가 여섯 개 이상 남는지 먼저 확인합니다.

결과를 정확히 읽는 방법

  • 중복을 금지하면 추첨 개수가 후보 수보다 많을 수 없습니다.
  • 범위의 양 끝값도 후보에 포함됩니다.
  • 로또 당첨 확률을 높이는 예측 기능이 아니라 무작위 번호 생성입니다.

완료 전 확인

최소·최대값과 제외값을 확인하고 당첨 예측이라는 오해 없이 오락용으로 사용하세요.

사용 전 꼭 확인하세요

난수 결과는 당첨을 예측·보장하지 않으며 구매는 무리하지 않는 범위에서 즐기세요.
