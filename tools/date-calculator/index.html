날짜·기간 계산기 사용 순서

  1. 준비: 시작일, 종료일, 더할 일수와 양끝 날짜 포함 여부를 입력합니다.
  2. 실행: 입력 형식과 선택 옵션을 확인한 뒤 실행 버튼을 누릅니다. 오류가 있으면 해당 항목 옆 안내부터 수정합니다.
  3. 확인: 기간 일수, 주 단위, 평일 수와 지정 일수 후 날짜를 계산합니다.

이 도구가 필요한 상황

두 날짜 사이의 일수와 특정 날짜에서 며칠 전·후를 계산합니다. 계약 기간, 프로젝트 일정, 여행 일정을 잡을 때 시작일 포함 여부를 선택해 해석 차이를 줄입니다.

실제 사용 예시

9월 1일부터 9월 2일까지의 경과일은 1일이지만 두 날짜를 모두 일정에 포함하면 2일입니다. “며칠 후”와 “n일째”가 다른 이유가 이 포함 기준입니다.

결과를 정확히 읽는 방법

  • 날짜는 기기 현지 시간의 자정 기준으로 계산해 일광절약시간이 있는 지역에서도 달력 날짜 차이를 우선합니다.
  • 법정 기간 계산은 초일 불산입 등 별도 규칙이 적용될 수 있습니다.
  • 영업일·공휴일 제외 계산은 제공하지 않습니다.

완료 전 확인

계약이나 행정기한은 관계 법령의 초일·말일·공휴일 규칙을 별도로 확인하세요.

개인정보와 한계

별도 안내가 없는 계산·파일 도구는 현재 브라우저에서 처리하며 입력 내용을 쓸모칸 서버에 저장하지 않습니다. 결과가 계약, 세금, 급여 또는 법률 판단에 영향을 준다면 최신 공식 자료와 담당 기관의 결과를 함께 확인하세요.
