Flexbox 플레이그라운드

정렬 옵션을 바꾸며 Flexbox 레이아웃과 CSS를 실험합니다.

무료로그인 없음모바일 지원브라우저 처리

도구를 불러오는 중입니다.

실험실 기능

이 페이지는 기능을 유지하되 검색 색인과 광고 대상에서 제외했습니다. 사용 의견을 반영해 설명과 검증 기준을 보강한 뒤 핵심 도구로 전환합니다.

Flexbox 플레이그라운드 사용 방법

  1. 방향, 주축·교차축 정렬, 줄바꿈, 간격과 항목 수를 선택합니다.
  2. 선택값이 적용된 배치와 복사 가능한 Flexbox CSS를 보여줍니다.

사용 전 확인

자식 요소의 크기와 flex-grow 설정에 따라 실제 프로젝트 결과는 달라질 수 있습니다.
