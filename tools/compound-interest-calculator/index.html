복리 계산기

원금과 수익률, 기간에 따른 복리 만기금액을 계산합니다.

복리 계산기 사용 순서

  1. 준비: 원금, 월 납입액, 연 수익률, 기간, 복리 주기와 세율을 입력합니다.
  2. 실행: 입력 형식과 선택 옵션을 확인한 뒤 실행 버튼을 누릅니다. 오류가 있으면 해당 항목 옆 안내부터 수정합니다.
  3. 확인: 총 납입액과 세전 수익, 세금, 세후 만기금을 계산합니다.

이 도구가 필요한 상황

초기 원금과 정기 납입액, 수익률, 기간, 복리 주기를 조합해 미래가치를 계산합니다. 적금·투자 목표를 비교하기 위한 시뮬레이션이며 수익을 보장하지 않습니다.

실제 사용 예시

연 5%를 매월 복리로 계산하는 경우와 연 1회 계산하는 경우 결과가 다릅니다. 매월 말 납입으로 가정하면 월초 납입보다 각 회차의 운용 기간이 짧습니다.

결과를 정확히 읽는 방법

  • 세금·수수료·물가상승률을 입력하지 않으면 명목 금액만 표시됩니다.
  • 시장 수익률은 일정하지 않으므로 고정 수익률 결과는 예측이 아니라 가정입니다.
  • 음수 수익률과 매우 긴 기간에서는 반올림 오차와 현실성도 검토해야 합니다.

완료 전 확인

세후 수익률과 수수료를 별도로 고려하고 납입 시점과 복리 주기를 실제 상품 조건에 맞추세요.

개인정보와 한계

별도 안내가 없는 계산·파일 도구는 현재 브라우저에서 처리하며 입력 내용을 쓸모칸 서버에 저장하지 않습니다. 결과가 계약, 세금, 급여 또는 법률 판단에 영향을 준다면 최신 공식 자료와 담당 기관의 결과를 함께 확인하세요.
