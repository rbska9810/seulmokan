내 IP 확인

현재 인터넷 연결의 공인 IP 주소를 확인합니다.

무료로그인 없음모바일 지원브라우저 처리

도구를 불러오는 중입니다.

실험실 기능

이 페이지는 기능을 유지하되 검색 색인과 광고 대상에서 제외했습니다. 사용 의견을 반영해 설명과 검증 기준을 보강한 뒤 핵심 도구로 전환합니다.

내 IP 확인 사용 방법

  1. 내 IP 확인 버튼을 누릅니다.
  2. 현재 연결의 공인 IPv4 또는 IPv6와 확인 시각을 표시합니다.

사용 전 확인

VPN, 프록시와 통신망 전환에 따라 값이 달라지며 ipify에 네트워크 요청을 보냅니다.

외부 전송 안내

공인 IP 확인을 위해 ipify 서비스에 네트워크 요청을 보냅니다. 브라우저와 해당 서비스의 정책에 따라 접속 로그가 처리될 수 있습니다.
