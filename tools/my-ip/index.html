내 IP 확인 사용 방법

내 IP 확인 버튼을 누릅니다.

결과에서 확인할 내용

현재 연결의 공인 IPv4 또는 IPv6와 확인 시각을 표시합니다.

이 도구가 필요한 상황

현재 인터넷 연결에 보이는 공인 IP를 확인해 접속 허용 목록이나 네트워크 점검에 활용합니다.

실제 사용 예시

회사 서비스가 접속 IP를 허용 목록에 등록해야 한다면 이 페이지의 결과를 관리자에게 전달하기 전에 VPN 사용 여부와 현재 네트워크를 확인하세요.

결과를 정확히 읽는 방법

  • 공인 IP는 공유기 내부 장치의 사설 IP와 다릅니다.
  • VPN·프록시·모바일망을 쓰면 표시되는 주소가 달라질 수 있습니다.
  • 조회 요청을 처리하는 외부 서비스가 접속 IP를 받습니다.

계산 방식

공인 IP는 인터넷 서비스가 내 연결을 구분하는 주소입니다. 집이나 회사의 공유기는 내부 장치에 사설 IP(10.x.x.x, 172.16~31.x.x, 192.168.x.x)를 나눠 주고, 바깥으로 나갈 때는 하나의 공인 IP로 묶어 보냅니다. 서버는 요청을 보낸 공인 IP를 그대로 읽어 돌려줍니다.

상황별 계산 사례

  • 공유기 안에서 컴퓨터가 192.168.0.12이어도 이 페이지는 통신사가 할당한 공인 IP를 보여 줍니다.
  • 회사 VPN을 켜면 표시되는 IP가 집 인터넷이 아니라 회사 VPN 출구 주소로 바뀝니다.
  • 스마트폰을 Wi-Fi에서 모바일 데이터로 바꾸면 IP도 다른 통신사 주소로 바뀝니다.
  • 관리자에게 접속 허용을 요청할 때는 IP와 함께 사용하는 네트워크(집, 회사, VPN)를 알려주면 확인이 빠릅니다.

자주 하는 실수

  • 공유기 관리 화면의 IP를 공인 IP로 착각하는 실수.
  • 유동 IP인데 허용 목록에 한 번 등록하고 계속 쓸 수 있다고 생각하는 실수.
  • IP를 SNS나 공개 게시글에 올리는 실수.
  • 통신사의 공유 IP(CGNAT, 100.64.x.x 대역) 환경에서 외부 접속이 안 되는 이유를 모르는 실수.

자주 묻는 질문

IPv4와 IPv6는 무엇이 다른가요?

IPv4는 점으로 구분한 4개 숫자(예: 203.0.113.5), IPv6는 콜론으로 구분한 긴 16진수 주소입니다. 환경에 따라 둘 중 하나만 보일 수 있습니다.

IP로 내 정확한 위치를 알 수 있나요?

대략적인 지역과 통신사 정도이며 집 주소까지는 알 수 없습니다.

조회한 IP가 저장되나요?

조회를 처리하는 외부 서비스는 요청을 받는 과정에서 IP를 볼 수 있습니다. 쓸모칸은 정적 사이트로 별도의 서버를 운영하지 않습니다.

완료 전 확인

네트워크를 바꾸거나 VPN을 켠 뒤에는 결과를 다시 확인하고 IP 주소를 공개 게시물에 남기지 마세요.
