내 IP 확인 사용 방법

내 IP 확인 버튼을 누릅니다.

결과에서 확인할 내용

현재 연결의 공인 IPv4 또는 IPv6와 확인 시각을 표시합니다.

이 도구가 필요한 상황

현재 인터넷 연결에 보이는 공인 IP를 확인해 접속 허용 목록이나 네트워크 점검에 활용합니다.

실제 사용 예시

회사 서비스가 접속 IP를 허용 목록에 등록해야 한다면 이 페이지의 결과를 관리자에게 전달하기 전에 VPN 사용 여부와 현재 네트워크를 확인하세요.

결과를 정확히 읽는 방법

  • 공인 IP는 공유기 내부 장치의 사설 IP와 다릅니다.
  • VPN·프록시·모바일망을 쓰면 표시되는 주소가 달라질 수 있습니다.
  • 조회 요청을 처리하는 외부 서비스가 접속 IP를 받습니다.

완료 전 확인

네트워크를 바꾸거나 VPN을 켠 뒤에는 결과를 다시 확인하고 IP 주소를 공개 게시물에 남기지 마세요.

외부 전송 안내

공인 IP 확인을 위해 ipify 서비스에 네트워크 요청을 보냅니다. 브라우저와 해당 서비스의 정책에 따라 접속 로그가 처리될 수 있습니다.

사용 전 꼭 확인하세요

VPN, 프록시와 통신망 전환에 따라 값이 달라지며 ipify에 네트워크 요청을 보냅니다.
