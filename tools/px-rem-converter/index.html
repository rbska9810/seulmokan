px ↔ rem 변환기

기준 폰트 크기에 맞춰 px와 rem 단위를 양방향으로 변환합니다.

무료로그인 없음모바일 지원브라우저 처리

도구를 불러오는 중입니다.

px ↔ rem 변환기 사용 방법

변환 방향, 기준 폰트 크기와 숫자 값을 입력합니다.

결과에서 확인할 내용

px 또는 rem 환산값과 적용한 계산식을 함께 확인할 수 있습니다.

이 도구가 필요한 상황

디자인 시안의 px 값을 사용자의 글꼴 크기 설정에 따라 변하는 rem 값으로 옮길 때 기준 크기를 함께 확인할 수 있습니다.

실제 사용 예시

루트 글꼴이 16px이면 24px은 1.5rem입니다. 사이트에서 html의 font-size가 20px이라면 같은 24px은 1.2rem이므로 기본값 16을 그대로 쓰지 마세요.

결과를 정확히 읽는 방법

  • px → rem은 픽셀값을 루트 글꼴 크기로 나눕니다.
  • rem → px은 rem값에 루트 글꼴 크기를 곱합니다.
  • 브라우저 확대와 사용자 글꼴 설정을 확인하려면 실제 화면에서도 검수해야 합니다.

완료 전 확인

변환한 CSS를 적용할 페이지의 실제 html font-size와 반응형 변경 규칙을 먼저 확인하세요.

사용 전 꼭 확인하세요

프로젝트의 html 루트 폰트 크기가 16px이 아닐 수 있으므로 실제 CSS 기준값을 먼저 확인하세요.
