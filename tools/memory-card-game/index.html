기억력 카드 게임 사용 방법

난이도를 선택하고 카드를 뒤집어 같은 그림의 위치를 찾습니다.

결과에서 확인할 내용

완료 시간, 뒤집은 횟수와 최고 기록을 확인합니다.

이 도구가 필요한 상황

카드를 뒤집어 짝을 찾으며 시도 횟수와 완료 시간을 확인하는 가벼운 기억력 게임입니다.

실제 사용 예시

처음에 본 그림 위치를 기억하고 두 장씩 선택합니다. 서로 다르면 뒤집힌 위치를 기억해 다음 시도에 활용하세요.

결과를 정확히 읽는 방법

  • 카드 배치가 새 게임마다 달라 기록에는 우연 요소가 있습니다.
  • 난이도나 카드 수가 다르면 완료 시간을 직접 비교할 수 없습니다.
  • 건강 상태나 인지 능력을 평가하는 검사로 사용하면 안 됩니다.

완료 전 확인

기록을 비교할 때 같은 난이도와 같은 기기에서 플레이했는지 확인하세요.

사용 전 꼭 확인하세요

카드 배치는 매번 보안 난수로 섞이며 새 게임을 누르면 진행 기록이 초기화됩니다.
