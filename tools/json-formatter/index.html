JSON 포맷터·검증기 사용 순서

  1. 준비: JSON 문자열, 들여쓰기와 키 정렬 여부를 입력합니다.
  2. 실행: 입력 형식과 선택 옵션을 확인한 뒤 실행 버튼을 누릅니다. 오류가 있으면 해당 항목 옆 안내부터 수정합니다.
  3. 확인: 문법을 검증해 정렬 또는 압축하며 오류 행과 열을 안내합니다.

이 도구가 필요한 상황

API 응답이나 설정 파일의 JSON 문법을 검사하고 들여쓰기·키 정렬·압축 결과를 만듭니다. 파싱에 실패하면 가능한 경우 오류 위치의 행과 열을 알려줍니다.

실제 사용 예시

마지막 속성 뒤의 불필요한 쉼표, 작은따옴표, 닫히지 않은 중괄호는 JSON 오류입니다. 검증 후 공백 2칸으로 정렬하면 코드 리뷰가 쉬워지고, 전송 전에는 압축해 크기를 줄일 수 있습니다.

결과를 정확히 읽는 방법

  • JSON은 주석, undefined, NaN, 작은따옴표 속성명을 허용하지 않습니다.
  • 키 정렬은 객체의 표시 순서만 바꾸며 배열의 항목 순서는 보존합니다.
  • 민감한 토큰이 포함된 데이터는 외부 검증기에 붙여넣지 말고 브라우저 처리 도구를 사용하는 편이 안전합니다.

완료 전 확인

정렬 결과를 원본 대신 바로 덮어쓰기 전에 숫자 정밀도와 큰 정수 표현이 유지되는지 확인하세요.

개인정보와 한계

별도 안내가 없는 계산·파일 도구는 현재 브라우저에서 처리하며 입력 내용을 쓸모칸 서버에 저장하지 않습니다. 결과가 계약, 세금, 급여 또는 법률 판단에 영향을 준다면 최신 공식 자료와 담당 기관의 결과를 함께 확인하세요.
