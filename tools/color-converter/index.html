HEX · RGB · HSL 변환기

도구를 불러오는 중입니다.

실험실 기능

이 페이지는 기능을 유지하되 검색 색인과 광고 대상에서 제외했습니다. 사용 의견을 반영해 설명과 검증 기준을 보강한 뒤 핵심 도구로 전환합니다.

HEX · RGB · HSL 변환기 사용 방법

  1. 3·6자리 HEX 또는 rgb() 값과 알파값을 입력합니다.
  2. HEX, RGB, HSL, RGBA 값을 동시에 변환해 보여줍니다.

사용 전 확인

알파값은 0부터 1까지이며 접근성 검토에는 실제 배경색도 함께 고려해야 합니다.
