실험실 기능

이 페이지는 기능을 유지하되 검색 색인과 광고 대상에서 제외했습니다. 사용 의견을 반영해 설명과 검증 기준을 보강한 뒤 핵심 도구로 전환합니다.

반응속도 테스트 사용 방법

  1. 측정 횟수를 선택하고 시작한 뒤 화면이 초록색으로 바뀔 때 클릭합니다.
  2. 각 시도의 반응시간과 평균·최고 기록을 확인합니다.
