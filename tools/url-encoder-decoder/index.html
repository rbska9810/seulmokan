URL 인코더·디코더 사용 방법

URL 전체, URL 구성요소 또는 쿼리 문자열과 처리 방식을 선택합니다.

결과에서 확인할 내용

퍼센트 인코딩·디코딩 또는 쿼리 키와 값을 출력합니다.

이 도구가 필요한 상황

URL의 경로 또는 쿼리에 들어갈 문자를 퍼센트 인코딩하고 다시 원문으로 복원합니다.

실제 사용 예시

“점심 메뉴”를 URL 값으로 옮기면 한글과 공백이 퍼센트 문자열로 바뀝니다. 전체 주소를 통째로 인코딩하면 :와 /까지 바뀌어 열 수 없는 링크가 될 수 있습니다.

결과를 정확히 읽는 방법

  • encodeURIComponent는 쿼리 값 한 개를 인코딩할 때 적합합니다.
  • 잘못된 % 시퀀스는 디코딩 오류가 납니다.
  • +를 공백으로 해석하는 양식 인코딩은 일반 퍼센트 디코딩과 구분해야 합니다.

완료 전 확인

생성한 주소를 실제로 열어 경로·쿼리·한글이 의도대로 전달되는지 확인하세요.

사용 전 꼭 확인하세요

전체 URL과 개별 파라미터는 인코딩 범위가 다르므로 목적에 맞는 방식을 선택하세요.
