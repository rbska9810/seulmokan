랜덤 비밀번호 생성기 사용 방법

길이, 생성 개수와 포함할 문자군을 선택합니다.

결과에서 확인할 내용

각 문자군을 최소 한 번 포함하는 보안 난수 비밀번호를 생성합니다.

이 도구가 필요한 상황

길이와 문자 종류를 선택해 새 비밀번호 후보를 생성합니다.

실제 사용 예시

16자 이상에 대문자·소문자·숫자·기호를 포함하면 짧은 단어 하나보다 추측하기 어렵습니다. 생성 후에는 다른 계정에서 쓰던 비밀번호와 겹치지 않게 하세요.

결과를 정확히 읽는 방법

  • 문자 종류를 많이 선택해도 총 길이가 짧으면 강도가 충분하지 않을 수 있습니다.
  • 서비스마다 허용하는 기호와 최대 길이가 다릅니다.
  • 생성한 비밀번호를 채팅이나 공개 문서에 붙여넣으면 비밀이 유지되지 않습니다.

계산 방식

비밀번호 강도는 보통 엔트로피(비트)로 가늠합니다. “길이 × log2(사용 가능한 문자 수)”로 계산하며 비트 수가 클수록 무작위 대입 공격에 오래 버팁니다. 길이가 늘어나면 강도가 곱으로 늘어나기 때문에 기호를 몇 개 더 섞는 것보다 길이를 늘리는 편이 효과적입니다.

상황별 계산 사례

  • 영문 소문자만 12자(26종)는 약 56비트입니다.
  • 대소문자·숫자·기호를 모두 섞은 94종 문자로 8자를 만들면 약 52비트로, 소문자 12자와 비슷한 수준입니다.
  • 같은 94종 문자로 16자를 만들면 약 105비트로 크게 높아집니다.
  • 영문·숫자 62종으로 20자를 만들면 약 119비트입니다. 사이트가 기호를 허용하지 않아도 길이로 보완할 수 있습니다.

자주 하는 실수

  • 생일·전화번호·키보드 배열(qwer1234)처럼 예측 가능한 패턴을 쓰는 실수.
  • 한 비밀번호를 여러 사이트에 재사용하는 실수: 한 곳이 유출되면 다른 곳도 뚫립니다.
  • 생성한 비밀번호를 메모장·채팅창에 평문으로 보관하는 실수.
  • 2단계 인증을 켜지 않고 비밀번호만 강하게 만드는 실수.

자주 묻는 질문

기호를 꼭 넣어야 하나요?

서비스 요구사항이 없다면 길이를 늘리는 편이 더 효과적입니다. 다만 일부 사이트는 기호를 요구하므로 안내에 맞추세요.

생성된 비밀번호는 저장되나요?

브라우저 안에서 만들어지며 쓸모칸 서버로 전송하지 않습니다. 그래도 화면 공유 중에는 노출에 주의하세요.

비밀번호를 얼마나 자주 바꿔야 하나요?

유출이 의심되지 않으면 주기적으로 바꾸는 것보다 고유하고 긴 비밀번호와 2단계 인증을 쓰는 것이 더 중요하다는 것이 최근의 일반적 권고입니다.
