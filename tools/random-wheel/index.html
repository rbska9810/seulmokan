룰렛 돌리기 사용 방법

후보를 한 줄씩 넣고 중복 제거와 당첨 항목 제거 여부를 선택합니다.

결과에서 확인할 내용

동일 확률로 하나를 추첨하고 회전 애니메이션과 결과를 표시합니다.

이 도구가 필요한 상황

직접 입력한 후보를 원판에 배치하고 회전 애니메이션으로 결과를 공개합니다.

실제 사용 예시

점심 후보를 김밥·국밥·파스타로 넣고 돌리면 멈춘 칸의 이름을 결과로 보여 줍니다. 회전하기 전에 후보를 확정해 모두 같은 선택 집합을 보게 하세요.

결과를 정확히 읽는 방법

  • 후보가 여러 번 입력되면 그 후보가 뽑힐 가능성이 커집니다.
  • 원판 애니메이션의 정지 위치와 텍스트 결과가 일치해야 합니다.
  • 오락용 추첨으로 금전·경품의 공정성을 보증하지 않습니다.

완료 전 확인

중복 후보와 빈 입력을 정리하고 원판의 표시 결과와 결과창 이름을 비교하세요.

사용 전 꼭 확인하세요

중요한 법적·금전적 추첨에는 참가자 합의와 별도 기록 절차가 필요합니다.
