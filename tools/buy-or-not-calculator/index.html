이거 살까 말까 계산기

사고 싶은 물건값을 내 노동시간과 사용 1회당 비용으로 바꿔 지름을 현실적으로 판단합니다.

무료로그인 없음모바일 지원브라우저 처리

도구를 불러오는 중입니다.

이거 살까 말까 계산기 사용 방법

물건 이름과 가격을 입력하고 월급 또는 시급 기준, 월 근무일수·하루 근무시간, 예상 사용 횟수를 설정합니다.

결과에서 확인할 내용

가격을 벌기 위해 필요한 노동시간·근무일과 사용 1회당 비용을 보여주고 판단 질문을 제공합니다.

이 도구가 필요한 상황

물건 가격을 일한 시간과 사용 횟수당 비용으로 바꿔 충동구매를 잠시 멈추고 비교합니다.

실제 사용 예시

10만원짜리 물건을 20번 쓸 예정이라면 1회당 비용은 5천원입니다. 월 실수령액 기준 노동시간은 실제 시급·세금·휴식 시간을 모두 반영한 급여 계산이 아닙니다.

결과를 정확히 읽는 방법

  • 예상 사용 횟수는 가정이므로 실제 사용이 적으면 1회당 비용이 커집니다.
  • 유지비·배송비·할부이자·되팔기 가격은 따로 고려해야 합니다.
  • 노동시간 환산은 소비 판단을 돕는 비유이지 재정 상담이 아닙니다.

완료 전 확인

필수 지출과 예산을 먼저 빼고 1회당 비용 외에 보관·수리 비용도 생각하세요.

사용 전 꼭 확인하세요

세후 실수령액을 입력해야 체감 노동시간에 가까우며 할인, 유지비, 이자와 되팔 때의 가치는 별도로 고려하세요.
