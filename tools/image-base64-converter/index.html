Base64 이미지 변환기

이미지 파일을 브라우저에서 Data URI 문자열로 변환합니다.

무료로그인 없음모바일 지원브라우저 처리

도구를 불러오는 중입니다.

Base64 이미지 변환기 사용 방법

5MB 이하의 PNG, JPEG, WebP, GIF 또는 SVG 파일을 선택합니다.

결과에서 확인할 내용

미리보기와 복사 가능한 Data URI 문자열을 만듭니다.

이 도구가 필요한 상황

작은 이미지의 data URL을 만들거나 data URL을 파일로 되돌려 HTML·CSS 테스트에 활용합니다.

실제 사용 예시

아이콘 파일을 data:image/png;base64,... 형식으로 바꾸면 별도 파일 요청 없이 시안에 넣을 수 있지만, 큰 사진은 문자열이 길어져 HTML과 CSS를 불필요하게 무겁게 만듭니다.

결과를 정확히 읽는 방법

  • Base64 문자열은 원본 바이너리보다 대체로 더 깁니다.
  • data URL에는 MIME 유형이 포함되어야 브라우저가 형식을 올바르게 해석합니다.
  • 비밀번호나 개인 사진의 data URL을 공개 코드에 붙여넣으면 내용이 그대로 노출됩니다.

계산 방식

Base64는 3바이트를 4개의 문자로 바꾸는 인코딩이라 원본보다 약 33% 커집니다. 이미지를 data:image/png;base64,… 형태의 Data URI로 만들면 별도 파일 요청 없이 HTML이나 CSS 안에 이미지를 직접 넣을 수 있습니다. 암호화가 아니라 단순한 표기 변환이므로 누구나 원래 이미지로 되돌릴 수 있습니다.

상황별 계산 사례

  • 3,000바이트 아이콘은 Base64 본문이 4,000문자가 되고, 앞의 data:image/png;base64, 22문자를 더하면 약 4,022문자입니다.
  • 100KB 이미지는 Base64로 약 133KB가 되고, 이 값이 HTML에 들어가면 이미지가 캐시되지 않아 페이지를 열 때마다 다시 내려받습니다.
  • 1~2KB짜리 작은 아이콘을 CSS 배경으로 넣으면 요청 수를 줄일 수 있어 유리하지만, 수십 KB가 넘는 사진은 일반 파일로 두는 편이 낫습니다.
  • 이메일 서명이나 HTML 메일에 넣은 Data URI 이미지는 Gmail 등 여러 메일 서비스에서 표시되지 않을 수 있어 외부 URL 이미지를 쓰는 편이 안전합니다.

자주 하는 실수

  • 큰 사진을 인라인으로 넣어 HTML과 CSS가 불필요하게 무거워지는 실수.
  • MIME 유형(image/png, image/jpeg 등)을 파일과 다르게 적는 실수.
  • 복사하는 과정에서 줄바꿈이나 공백이 끼어 이미지가 깨지는 실수.
  • 개인 사진이나 문서 스캔을 Base64로 바꿔 공개 저장소에 올려 내용이 그대로 노출되는 실수.

자주 묻는 질문

Base64로 바꾸면 이미지가 보호되나요?

아닙니다. 형식만 바뀌는 것이라 누구나 되돌릴 수 있고 보안 수단이 아닙니다.

SVG도 Base64가 필요한가요?

SVG는 텍스트라 Base64 없이 URL 인코딩한 Data URI로도 넣을 수 있고, 그쪽이 더 짧은 경우가 많습니다.

콘텐츠 보안 정책(CSP)이 있으면 어떻게 되나요?

img-src에 data:가 허용되지 않으면 Data URI 이미지가 차단됩니다. 서버 설정을 확인하세요.

완료 전 확인

큰 이미지는 파일로 제공하고, 변환 결과가 실제로 열리는지와 파일 유형을 확인하세요.
