엑셀 CSV 한글 깨짐·앞자리 0·날짜 변환 문제 해결법

복사한 목록이나 CSV를 Excel로 옮길 때 생기는 한글 깨짐(UTF-8 BOM), 전화번호 앞자리 0 사라짐, 1-2가 날짜로 바뀌는 문제, 16자리 숫자 반올림과 수식 주입을 해결하는 방법입니다.

작성·검토: 쓸모칸 운영자게시 2026-09-20 · 최종 수정 2026-10-12 · 읽는 시간 약 4분
핵심 요약
  • CSV를 Excel에서 열 때 한글이 깨지면 UTF-8 BOM이 붙은 파일로 저장하거나 데이터 가져오기 기능으로 인코딩을 지정합니다.
  • 전화번호·우편번호·상품코드는 숫자가 아니라 텍스트로 저장해야 앞자리 0이 남습니다.
  • Excel은 숫자를 15자리까지만 정확히 저장해 16자리 카드번호의 마지막 자리가 0으로 바뀝니다.

메신저나 웹페이지에서 복사한 명단을 엑셀에 붙여 넣으면 한 셀에 몰리거나, 전화번호 앞의 0이 사라지거나, "1-2"가 1월 2일로 바뀌는 일이 자주 생깁니다. 대부분 Excel이 값을 "똑똑하게" 해석하려다 생기는 문제라서 원인을 알면 미리 막을 수 있습니다.

문제별 원인과 해결

증상원인해결
한글이 ¿½ 같은 문자로 깨짐UTF-8 파일을 Excel이 다른 인코딩으로 읽음UTF-8 BOM으로 저장하거나 데이터 → 텍스트/CSV에서 65001 UTF-8 선택
010-1234-5678이 숫자로 바뀌거나 0이 사라짐숫자로 자동 인식열 형식을 텍스트로 지정 후 붙여넣기
1-2, 3/4가 날짜로 바뀜날짜 자동 인식텍스트 형식 지정 또는 앞에 작은따옴표(')
1.23E+15처럼 표시됨긴 숫자를 지수로 표시텍스트 형식으로 저장
16자리 숫자 끝자리가 0Excel 숫자 정밀도 15자리카드·계좌·주문번호는 반드시 텍스트
한 줄이 한 셀에 몰림구분자(탭·쉼표) 불일치구분자를 명시해 다시 변환

탭과 쉼표 구분 이해하기

엑셀이나 구글 시트에서 범위를 복사하면 열은 탭, 행은 줄바꿈으로 구분된 텍스트가 클립보드에 들어갑니다. 반면 CSV 파일은 쉼표로 열을 나눕니다. 주소처럼 셀 안에 쉼표가 들어 있는 값은 "서울시 강남구, 101호"처럼 큰따옴표로 감싸야 한 셀로 유지되고, 셀 안의 큰따옴표는 두 번("")으로 적어야 합니다. 이 규칙을 지키지 않으면 열이 하나씩 밀려 이후 데이터 전체가 어긋납니다.

앞자리 0과 긴 숫자 보존

Excel은 셀에 입력된 값이 숫자처럼 보이면 숫자로 저장합니다. 숫자 01012345678은 1012345678이 되고, 16자리 이상 숫자는 15자리 이후가 0으로 바뀝니다. 한 번 숫자로 저장되면 원래 값을 되살릴 수 없으므로 붙여넣기 전에 열 형식을 텍스트로 바꾸거나, 변환 도구에서 숫자 자동 인식을 끄고 저장해야 합니다.

CSV 한글 깨짐 해결

Windows용 Excel은 BOM(파일 앞의 인코딩 표시)이 없는 UTF-8 CSV를 다른 인코딩으로 읽어 한글이 깨지는 경우가 있습니다. 해결 방법은 두 가지입니다. 하나는 UTF-8 BOM이 붙은 CSV로 저장하는 것이고, 다른 하나는 Excel의 데이터 → 텍스트/CSV 가져오기에서 파일 원본을 "65001: 유니코드(UTF-8)"로 지정하는 것입니다. 쓸모칸 목록 Excel 변환은 CSV 다운로드에 BOM을 붙이고, 처음부터 XLSX로 저장하는 옵션도 제공합니다.

수식 주입(CSV 인젝션) 주의

외부에서 받은 데이터의 셀이 =, +, -, @로 시작하면 Excel이 이를 수식으로 실행할 수 있습니다. 악의적인 수식은 외부 링크를 열거나 다른 셀 값을 전송하려 시도할 수 있습니다. 신뢰할 수 없는 목록은 이런 값 앞에 작은따옴표를 붙여 문자로 저장하고, 파일을 열 때 나오는 외부 콘텐츠 경고를 무시하지 마세요.

변환 전 점검 순서

  1. 원본에서 한 행이 무엇을 뜻하는지, 첫 줄이 머리글인지 확인
  2. 구분자가 탭인지 쉼표인지 확인
  3. 앞자리 0, 긴 번호, 날짜처럼 보이는 코드가 있는 열을 텍스트로 지정
  4. 미리보기에서 열 개수가 모든 행에서 같은지 확인
  5. 저장 후 다시 열어 행 수와 마지막 행 값을 원본과 대조

자주 묻는 질문

구글 시트에서는 같은 문제가 없나요?

구글 시트도 숫자·날짜 자동 인식이 있어 앞자리 0과 날짜 변환 문제가 생깁니다. 서식 → 숫자 → 일반 텍스트로 먼저 지정하세요.

XLSX와 CSV 중 무엇으로 저장해야 하나요?

다른 프로그램에 업로드할 데이터는 CSV, 사람이 열어볼 표는 서식과 텍스트 형식을 유지하는 XLSX가 안전합니다.

이 글은 일반적인 기준을 설명하는 정보이며 개인별 법률·세무 판단을 대신하지 않습니다. 중요한 결정 전에는 본문에 적은 공식 기관 자료나 전문가 상담으로 확인하세요. 내용 오류는 문의 페이지로 알려주시면 확인 후 수정합니다.
