글자수와 바이트 수가 다른 이유: UTF-8 한글·이모지 계산법

공백 포함·제외 글자수와 UTF-8 바이트, 한글 2바이트 기준의 차이를 지원서와 문자 예시로 설명합니다.

작성·검토: 쓸모칸 운영자게시·수정 2026-09-20

화면에 보이는 글자 수와 컴퓨터가 저장하는 바이트 수는 같은 개념이 아닙니다. 영문과 숫자는 UTF-8에서 보통 1바이트지만 한글 음절은 보통 3바이트입니다. 이모지는 여러 코드 포인트가 결합되어 훨씬 커질 수 있습니다.

한글 100자는 몇 바이트일까

순수 한글 음절 100자는 UTF-8에서 대체로 300바이트입니다. 공백·영문·숫자·문장부호가 섞이면 각 문자의 바이트가 달라 단순히 글자 수에 3을 곱할 수 없습니다. 실제 문자열을 기준으로 계산해야 합니다.

한글 2바이트 기준은 무엇인가

일부 오래된 채용·문자 시스템은 한글 2바이트, 영문·숫자 1바이트라는 자체 규칙을 사용합니다. 이는 UTF-8 실제 파일 크기와 다릅니다. 입력 화면에 “한글 2바이트”라고 명시된 경우에만 해당 기준을 선택하세요.

제출 전에 확인할 것

  • 제한이 공백 포함인지 제외인지 확인합니다.
  • 글자 수인지 byte 제한인지 확인합니다.
  • 줄바꿈과 이모지도 제한에 포함되는지 확인합니다.
  • 최대치에 딱 맞추기보다 수정 여유를 남깁니다.
