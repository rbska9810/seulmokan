검색 결과에 보이는 제목·설명 쓰는 법: title과 meta description 글자 수와 작성 기준

검색 결과에 노출되는 title과 meta description의 역할, 잘리지 않는 글자 수 감각, 중복·키워드 나열 같은 흔한 실수와 페이지별로 고유하게 쓰는 체크리스트를 정리합니다.

작성·검토: 쓸모칸 운영자게시 2026-10-18 · 최종 수정 2026-10-18 · 읽는 시간 약 4분
핵심 요약
  • title은 검색 결과의 파란 제목과 브라우저 탭 이름에 쓰이고, meta description은 요약 문장 후보로 쓰입니다.
  • 구글은 description을 그대로 쓰지 않고 검색어에 맞게 본문에서 다른 문장을 뽑아 보여줄 수도 있습니다.
  • 페이지마다 고유한 제목과 설명을 쓰고, 핵심 키워드는 앞쪽에 한 번 자연스럽게 넣는 것이 기본입니다.

검색 결과에서 사용자가 가장 먼저 보는 것은 제목과 두세 줄의 설명입니다. 같은 순위여도 무엇이 적혀 있는지에 따라 클릭률이 크게 달라지므로, 별도의 큰 작업 없이도 효과를 볼 수 있는 부분입니다. 반대로 키워드를 나열하거나 모든 페이지에 같은 문구를 쓰면 클릭도 줄고 품질 평가에도 불리합니다.

1. title과 description의 역할

항목어디에 쓰이나작성 목적
title검색 결과 제목, 브라우저 탭, 북마크이 페이지가 무엇인지 한눈에 알리기
meta description검색 결과 요약 문장의 후보클릭해서 얻을 내용을 구체적으로 설명하기
og:title / og:description카카오톡·SNS 공유 미리보기공유 링크의 첫인상
canonical검색엔진에 알리는 대표 주소중복 페이지 정리

description은 검색 순위를 직접 올리는 요소가 아니라고 구글이 밝혀 왔습니다. 그러나 클릭을 부르는 문장이므로 간접적으로 성과에 영향을 줍니다.

2. 글자 수는 얼마나 맞춰야 하나

검색 결과는 글자 수가 아니라 화면 가로 픽셀 폭으로 잘립니다. 한글은 영문보다 폭이 넓어서 제목은 대략 30자 안팎, 설명은 모바일 기준 80자 안팎에서 말줄임표가 생기는 경우가 많습니다. 정확한 한계는 기기와 글꼴에 따라 달라지므로 한글 제목 30자 이내, 설명 80~120자 이내로 작성하고 중요한 내용은 앞쪽에 두세요. 미리보기 도구로 잘림 여부를 확인하는 것이 확실합니다.

3. 좋은 제목의 구조

  • 핵심 대상 + 구체적 가치: "퇴직금 계산기"보다 "퇴직금 계산기: 입사일·월급으로 예상 금액 확인"처럼 쓰면 무엇을 얻는지 드러납니다.
  • 핵심 키워드는 앞쪽에 둡니다. 뒤쪽은 잘릴 수 있습니다.
  • 사이트 이름은 끝에 붙입니다(예: | 쓸모칸). 모든 페이지가 같은 접두어로 시작하면 구분이 어렵습니다.
  • 숫자나 연도는 실제로 그 내용을 다룰 때만 씁니다(예: 2026 기준). 갱신하지 않을 글에 연도를 넣으면 오히려 낡아 보입니다.

4. 좋은 설명의 구조

설명은 한 문장으로 "무엇을 알 수 있는지"와 "어떤 방법인지"를 함께 적습니다. 예를 들어 "평균임금과 재직일수 계산법을 실제 숫자 예시로 설명합니다"는 구체적이지만 "최고의 계산기, 지금 바로 이용하세요"는 정보가 없습니다. 과장 표현, 느낌표 반복, 키워드 나열은 피하세요.

구분나쁜 예나은 예
제목계산기 | 무료 계산기 | 쓸모칸연차 계산기: 입사일 기준 발생 일수와 미사용 수당 | 쓸모칸
설명최고의 도구! 지금 사용하세요입사일과 근속기간을 넣으면 연차 일수와 미사용 연차수당 예상액을 계산합니다.

5. 사이트 전체에서 점검할 것

  • 중복: 서로 다른 페이지가 같은 title이나 description을 쓰고 있지 않은지 확인합니다. 검색 콘솔의 "중복 제목" 항목이나 사이트 검색(site:도메인)으로 볼 수 있습니다.
  • 비어 있는 값: description이 없으면 검색엔진이 본문에서 임의로 뽑습니다.
  • 페이지 내용과의 일치: 제목에서 약속한 내용이 본문에 없으면 이탈이 늘고 품질 신호가 나빠집니다.
  • canonical과 sitemap: 대표 주소가 일치해야 검색엔진이 같은 페이지로 판단합니다.

6. 바꾼 뒤 확인 방법

제목이나 설명을 고쳐도 검색 결과에 반영되려면 크롤링을 기다려야 하며 보통 며칠에서 몇 주가 걸립니다. 서치 콘솔에서 해당 URL의 색인 생성을 요청하면 속도를 조금 앞당길 수 있습니다. 다만 구글이 검색어에 따라 제목과 설명을 자체 판단으로 바꿔 보여주는 경우도 있으므로, 같은 검색어에서 2~4주간 클릭률 변화를 지켜보세요.

자주 묻는 질문

description은 꼭 써야 하나요?

필수는 아니지만 쓰는 것을 권장합니다. 없으면 검색엔진이 본문 일부를 가져오므로 의도와 다르게 보일 수 있습니다.

keywords 메타 태그는 효과가 있나요?

구글은 keywords 메타 태그를 검색 순위에 사용하지 않는다고 밝혔습니다. 신경 쓰지 않아도 됩니다.

제목을 자주 바꿔도 되나요?

잦은 변경은 효과 비교가 어렵게 만듭니다. 한 번 바꾼 뒤 최소 2~4주 지켜보고 판단하는 편이 좋습니다.
