브라우저에서 처리되는 온라인 도구는 파일을 어디로 보낼까

로컬 브라우저 처리, 외부 CDN 모델 다운로드, API 요청의 차이를 구분해 개인정보와 파일을 안전하게 다루는 법입니다.

작성·검토: 쓸모칸 운영자게시·수정 2026-09-20

“브라우저에서 처리”는 입력 파일을 서비스 서버로 업로드하지 않고 현재 기기의 메모리와 CPU에서 계산한다는 뜻입니다. 하지만 페이지 코드, 글꼴, AI 모델을 내려받는 과정에서는 외부 서버와 연결될 수 있습니다.

로컬 처리와 외부 API 구분

이미지 자르기나 텍스트 변환은 브라우저만으로 끝낼 수 있습니다. 반면 공인 IP 확인이나 서버형 QR 생성은 기능 특성상 입력 또는 접속 정보가 외부 API로 전달됩니다.

CDN에서 라이브러리를 내려받는 경우

파일 내용은 보내지 않더라도 CDN 사업자는 IP 주소, 브라우저 정보, 요청 시각 같은 기술 로그를 처리할 수 있습니다. 민감한 작업은 네트워크와 개인정보 안내를 확인하세요.

사용자가 할 수 있는 보호 조치

주민등록번호·계좌번호처럼 불필요한 정보는 입력하지 말고, 처리 후 탭을 닫으며, 공용 컴퓨터에서는 다운로드 파일과 브라우저 기록을 정리하세요.
