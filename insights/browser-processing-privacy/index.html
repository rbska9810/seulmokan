온라인 도구에 올린 파일은 어디로 갈까: 브라우저 처리 확인법

로컬 브라우저 처리와 서버 업로드의 차이, 개발자 도구 네트워크 탭으로 전송 여부를 직접 확인하는 방법, 쓸모칸 도구별 외부 요청 목록과 안전한 사용 습관을 정리합니다.

작성·검토: 쓸모칸 운영자게시 2026-09-20 · 최종 수정 2026-10-12 · 읽는 시간 약 3분
핵심 요약
  • "브라우저에서 처리"는 파일이 서비스 서버로 업로드되지 않고 내 기기에서 계산된다는 뜻입니다.
  • 그래도 페이지 코드, 글꼴, AI 모델을 내려받을 때는 외부 서버와 통신이 일어납니다.
  • 브라우저 개발자 도구의 네트워크 탭을 보면 파일이 실제로 전송되는지 누구나 확인할 수 있습니다.

계약서 사진을 자르거나, 주민등록번호가 들어간 목록을 정리하거나, 가족사진의 배경을 지울 때 "이 파일이 어디에 저장되는지"는 중요한 문제입니다. 서비스 설명만 믿기보다 직접 확인하는 방법을 알아두면 어떤 온라인 도구를 쓰든 판단할 수 있습니다.

세 가지 처리 방식

방식파일 이동예시
로컬 처리내 기기 메모리 안에서만 처리텍스트 변환, 계산기, 이미지 자르기·압축
리소스 다운로드 + 로컬 처리AI 모델·라이브러리를 내려받고 처리는 기기에서AI 배경 제거, PSD 변환, Excel 생성
서버(API) 처리입력값이나 파일이 외부 서버로 전송공인 IP 확인, 서버형 QR 생성, 클라우드 변환 서비스

직접 확인하는 방법: 네트워크 탭

  1. PC 크롬이나 엣지에서 도구 페이지를 열고 F12를 눌러 개발자 도구를 엽니다.
  2. Network(네트워크) 탭을 선택하고 목록을 비웁니다(🚫 아이콘).
  3. 파일을 선택하고 도구를 실행합니다.
  4. 새로 생긴 요청 중 크기가 내 파일만큼 큰 업로드(Method가 POST이고 Request Payload에 파일이 있는 요청)가 있는지 봅니다.

모델이나 라이브러리를 내려받는 GET 요청은 보여도, 내 파일 크기만큼의 POST 요청이 없다면 파일은 업로드되지 않은 것입니다. 더 간단한 확인법으로, 페이지와 모델을 한 번 불러온 뒤 인터넷 연결을 끊고 실행해도 결과가 나온다면 로컬 처리입니다.

쓸모칸 도구의 외부 요청

  • 공인 IP 확인: IP 조회 서비스(ipify)에 요청합니다. 그 서비스는 요청을 보낸 IP를 알게 됩니다.
  • QR코드 생성: 입력한 URL이나 텍스트가 QR 이미지 생성 서버로 전송됩니다. 비밀번호나 개인정보를 QR로 만들지 마세요.
  • AI 배경 제거·PSD 변환·Excel 생성: 처리에 필요한 모델과 라이브러리 파일을 CDN에서 내려받습니다. 사진과 문서 내용은 전송하지 않습니다.
  • 방문 통계: Google Analytics로 페이지 방문과 도구 실행 여부를 집계하지만, 도구에 입력한 값과 파일 내용은 보내지 않습니다.

CDN 요청에서 남는 정보

파일 내용이 전송되지 않아도 CDN 사업자는 웹 요청의 특성상 접속 IP 주소, 브라우저 정보, 요청 시각 같은 기술 로그를 처리할 수 있습니다. 이는 일반적인 웹사이트 방문에서도 동일하게 발생하는 정보입니다.

어떤 도구를 쓰든 지킬 습관

  • 필요 없는 민감정보(주민등록번호 뒷자리, 계좌·카드번호)는 처리 전에 지우거나 가립니다.
  • 공용 컴퓨터에서는 다운로드 폴더의 결과 파일과 브라우저 기록을 정리합니다.
  • 회사 기밀 문서는 회사 보안 정책이 외부 웹 도구 사용을 허용하는지 먼저 확인합니다.
  • "무료 변환" 서비스의 개인정보처리방침에서 업로드 파일 보관 기간을 확인합니다.

자주 묻는 질문

로컬 처리 도구도 결과 파일을 저장하나요?

쓸모칸은 결과를 서버에 저장하지 않습니다. 결과는 사용자가 다운로드 버튼을 눌렀을 때만 내 기기에 저장되고, 탭을 닫으면 메모리에서 사라집니다.

모바일에서는 어떻게 확인하나요?

모바일 브라우저는 네트워크 탭을 쓰기 어렵습니다. 페이지를 연 뒤 비행기 모드로 바꿔 실행해 보는 방법이 가장 간단합니다.

이 글은 일반적인 기준을 설명하는 정보이며 개인별 법률·세무 판단을 대신하지 않습니다. 중요한 결정 전에는 본문에 적은 공식 기관 자료나 전문가 상담으로 확인하세요. 내용 오류는 문의 페이지로 알려주시면 확인 후 수정합니다.
