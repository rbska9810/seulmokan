JPG·PNG·WebP·AVIF·HEIC 차이: 용도별 이미지 형식 고르는 법

사진·로고·캡처·투명 배경 이미지에 맞는 형식, 화질 설정값, 해상도와 용량의 관계, 아이폰 HEIC 변환과 위치정보(EXIF) 제거까지 이미지 저장 기준을 정리합니다.

작성·검토: 쓸모칸 운영자게시 2026-09-20 · 최종 수정 2026-10-12 · 읽는 시간 약 4분
핵심 요약
  • 사진은 JPG나 WebP, 로고·아이콘·글자가 많은 캡처는 PNG, 투명 배경 사진은 PNG나 WebP가 기본 선택입니다.
  • 용량을 가장 크게 줄이는 방법은 화질 숫자보다 가로세로 픽셀 크기를 줄이는 것입니다.
  • 캔버스로 다시 저장하는 브라우저 도구는 대개 촬영 위치 같은 EXIF 정보가 빠집니다.

"사진 용량 줄이는 법"을 찾다 보면 화질 슬라이더부터 만지게 되지만, 실제로는 형식 선택 → 픽셀 크기 → 화질 순서로 결정해야 결과가 좋습니다. 같은 사진도 형식만 바꿔 용량이 절반이 되기도 하고, 반대로 화질을 아무리 낮춰도 줄지 않기도 합니다.

형식별 특징 비교

형식압축투명도잘 맞는 이미지주의할 점
JPG손실불가일반 사진글자 주변이 뭉개짐, 저장할수록 손실 누적
PNG무손실가능로고, 아이콘, 화면 캡처, 도표사진은 용량이 매우 큼
WebP손실·무손실가능웹용 사진과 투명 이미지일부 오래된 프로그램·제출 시스템 미지원
AVIF손실·무손실가능고압축이 필요한 웹 사진인코딩이 느리고 지원 환경이 WebP보다 적음
HEIC손실가능아이폰 기본 사진윈도우·웹 업로드에서 열리지 않는 경우가 많음
GIF무손실(256색)1비트짧은 단순 애니메이션사진·긴 영상은 용량이 큼

상황별 추천

  • 블로그·쇼핑몰 사진: 긴 변 1,200~1,600px, WebP 또는 JPG 화질 75~85
  • 제출용 서류 사진: 제출처가 지정한 형식(대개 JPG)과 용량 제한을 우선
  • 로고·아이콘: PNG(가능하면 벡터인 SVG 원본 보관)
  • 화면 캡처·표: PNG. 글자가 선명해야 하므로 JPG는 피합니다.
  • 투명 배경 상품 이미지: PNG 또는 WebP. JPG로 저장하면 투명 부분이 흰색이나 검은색으로 채워집니다.

픽셀 크기가 용량을 좌우합니다

4,000×3,000px 사진(1,200만 픽셀)을 1,600×1,200px(192만 픽셀)로 줄이면 픽셀 수가 약 1/6로 줄어 용량도 비슷한 비율로 줄어듭니다. 화면에 600px 폭으로 보여줄 이미지를 4,000px로 올리는 것은 불필요하게 무거운 페이지를 만드는 가장 흔한 원인입니다. 고해상도 화면을 고려해도 표시 크기의 2배 정도면 충분합니다.

화질 값은 얼마가 적당할까

JPG·WebP의 화질 75~85 사이에서는 대부분의 사진에서 차이를 눈으로 구분하기 어렵지만 용량은 크게 줄어듭니다. 60 아래로 내리면 하늘이나 피부처럼 부드러운 색 변화에 계단 현상이 생기고 글자 주변에 얼룩이 보이기 시작합니다. 압축 후에는 100% 확대해 얼굴, 글자, 제품 라벨을 확인하세요.

아이폰 HEIC 사진

아이폰의 '고효율' 촬영 설정은 HEIC로 저장합니다. 용량은 작지만 윈도우나 일부 웹사이트에서 업로드가 되지 않을 수 있습니다. 아이폰 설정 → 카메라 → 포맷에서 '높은 호환성'을 선택하면 JPG로 저장되고, 이미 찍은 사진은 사진 앱에서 공유하거나 변환 도구로 JPG로 바꿀 수 있습니다.

위치정보(EXIF) 확인

스마트폰 사진에는 촬영 일시, 기기 모델, 설정에 따라 GPS 위치가 함께 저장될 수 있습니다. 중고거래나 SNS에 집에서 찍은 사진을 올릴 때는 위치정보가 남아 있지 않은지 확인하세요. 쓸모칸의 이미지 용량 줄이기처럼 브라우저 캔버스로 다시 그려 저장하는 도구는 일반적으로 EXIF 정보를 포함하지 않은 새 파일을 만듭니다.

자주 묻는 질문

PNG를 PNG로 압축했는데 용량이 거의 그대로예요.

PNG는 무손실 형식이라 화질 설정이 의미가 없습니다. 사진이라면 WebP나 JPG로, 로고라면 픽셀 크기를 줄여보세요.

WebP로 저장했더니 업로드가 안 됩니다.

제출 시스템이 WebP를 지원하지 않는 경우입니다. JPG(사진) 또는 PNG(투명·그래픽)로 다시 저장하세요.

이 글은 일반적인 기준을 설명하는 정보이며 개인별 법률·세무 판단을 대신하지 않습니다. 중요한 결정 전에는 본문에 적은 공식 기관 자료나 전문가 상담으로 확인하세요. 내용 오류는 문의 페이지로 알려주시면 확인 후 수정합니다.
