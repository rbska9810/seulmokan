# 쓸모칸 (SEULMOKAN)

쓸모 있는 온라인 도구를 한 칸에 모으는 정적 유틸리티 허브입니다.

## 현재 구현 범위

- 등록된 도구를 자동 집계하는 확장형 도구 디렉터리
- 실시간 검색 및 카테고리 필터
- 반응형 레이아웃
- 라이트·다크 모드
- 검색 및 소셜 메타데이터
- 구조화 데이터(JSON-LD)
- Google AdSense 배치용 슬롯

도구를 추가하거나 정리하면 메인 화면의 전체·카테고리별 개수와 사이트맵이 함께 갱신되도록 구성되어 있습니다.

현재 구현·검증 범위와 배포 전 확인사항은 [PROJECT_STATUS.md](./PROJECT_STATUS.md)에 기록합니다.
